# Процедурная туманность

Страница GitHub Pages генерирует звёздное небо прямо в браузере. Новое открытие страницы выбирает случайный seed. Параметр `?seed=3fae29` закрепляет сцену. Кадр перерисовывается при изменении размера окна.

Рендер WebGL 2 использует клиентский GPU при аппаратном ускорении. Статическая страница не передаёт изображение с сервера. Для браузеров без WebGL 2 есть упрощённый Canvas 2D. Веб-версия переносит композицию, цветовые коридоры, пылевые слои и рассеяние звёздного света в GLSL со своей реализацией.

Локальный генератор PNG версии 5 находится в `desktop/`. Он поддерживает пакетный вывод, масштаб 0,8–1,2× и количество звёзд 70–100% от базового. Для CUDA нужен совместимый CuPy. Без него используется многопоточный CPU.

```sh
python -m pip install -r desktop/requirements.txt
python desktop/generate.py --wallpaper wallpapers --wallpaper-count 10
```
