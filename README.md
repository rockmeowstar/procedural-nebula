# Процедурная туманность

Страница GitHub Pages запускает генератор версии 5 из `desktop/`. Новое открытие выбирает случайный seed. Параметр `?seed=a731c54381f21acf21fa05ab93bb4cc5c1a396c6` закрепляет seed. Ширина и высота кадра равны размерам видимой области в CSS-пикселях. При изменении окна текущий кадр заполняет его пропорционально и заменяется, когда готов новый кадр с тем же seed.

В браузере CPU-ветка генератора выполняется через Pyodide в Web Worker. При первом открытии среда загружает NumPy и Pillow. Цветовой режим соответствует одиночному запуску с `--wallpaper-palette uniform`.

Локальный генератор PNG версии 5 находится в `desktop/`. Он поддерживает пакетный вывод, масштаб 0,8–1,2× и количество звёзд 70–100% от базового. Для CUDA нужен совместимый CuPy. Без него используется многопоточный CPU.

```sh
python -m pip install -r desktop/requirements.txt
python desktop/generate.py --wallpaper wallpapers --wallpaper-count 10
```
